# Bellbird BookFlow Installation Guide

## 1. Purpose

This guide explains how Bellbird Books stakeholders can install and run Bellbird BookFlow on a local computer.

## 2. System Requirements

The computer requires:

- PHP 8.1 or later
- PHP PDO SQLite extension
- Git
- A modern web browser
- Visual Studio Code or another code editor
- Internet access for downloading the repository

No separate database server is required because Bellbird BookFlow uses SQLite.

Open a terminal and run:

git clone https://github.com/IT21195884/Bellbird-BookFlow.git
