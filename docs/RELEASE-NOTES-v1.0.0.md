# Bellbird BookFlow Version 1.0.0

## Release Summary

Bellbird BookFlow version 1.0.0 is the first complete release of the stock and customer-order management system developed for Bellbird Books.

## Stock Management Features

- Record new-book titles and quantities.
- Adjust new-book stock quantities.
- Record individual second-hand copies.
- Update new and second-hand book records.
- Remove sold or unavailable stock.
- Search new and second-hand stock together.
- Filter stock by shop section.
- Record second-hand intake and purchase details.

## Customer Order Features

- Record customer contact details and preferences.
- Validate telephone numbers and email addresses.
- Create and search customer orders.
- Move orders through their lifecycle.
- View outstanding orders.
- Correct or cancel orders.
- Record customer contact attempts.
- Process eligible uncollected orders and deposit credit.

## Configuration Management

The project uses:

- Git and GitHub version control.
- Main, development, feature and release branches.
- Environment-based configuration.
- SQLite database configuration.
- Meaningful commit messages.
- A project change log.
- GitHub Actions quality checking.
- Installation, testing and user documentation.

## Known Limitations

- Authentication and role-based access are outside the agreed Jira scope.
- Email and text messages are not automatically sent.
- Production hosting must be configured separately.
